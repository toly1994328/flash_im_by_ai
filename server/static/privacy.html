闪讯隐私政策

生效日期：2026年5月24日 | 版本：1.0

我们深知个人信息对您的重要性，将尽全力保护您的隐私安全。请您在使用闪讯前仔细阅读本隐私政策。

一、我们收集哪些信息

信息类型具体内容收集目的
账号信息手机号 / GitHub ID登录验证、账号唯一标识
个人资料昵称、头像、个性签名展示给其他用户，方便社交
设备信息设备型号、操作系统、设备标识符登录安全审计、问题排查
网络信息IP 地址登录日志记录、安全防护
聊天内容文字、图片、语音、视频、文件消息传输与存储，确保您能正常收发消息
好友关系好友列表、群聊成员提供社交功能

二、我们如何使用信息

我们收集的信息仅用于以下目的：

  • 提供即时通讯核心服务（消息收发、好友管理、群聊）
  • 保障账号安全（异常登录检测、风险提醒）
  • 改善产品体验（问题排查、性能优化、功能改进）
  • 履行法律法规要求的义务

我们承诺：不会将您的个人信息出售给任何第三方，不会用于广告推送或商业营销。

三、信息存储与安全

  • 数据存储在我们的云服务器上，采用加密传输
  • 密码使用 Argon2 算法加密存储，即使数据泄露也无法还原明文
  • 定期备份数据，防止意外丢失
  • 聊天记录在服务端持久化存储，客户端本地有缓存加速访问
  • 我们会采取合理的技术和管理措施保护您的信息安全

四、信息共享与披露

以下情况我们可能共享您的信息：

  • 您主动发送的消息会传递给接收方（这是通讯功能的本质）
  • 您的昵称和头像对好友和群成员可见
  • 法律法规要求或政府机关依法调取时

除上述情况外，我们不会向任何第三方共享您的个人信息。

五、您的权利

您对自己的个人信息享有以下权利：

  • 查看和修改：随时修改昵称、头像、个性签名等个人资料
  • 删除：删除本地聊天记录
  • 注销：申请注销账号，我们将删除您的所有数据（联系闪讯团队处理）

权限使用场景是否必须

七、未成年人保护

本应用不面向 14 周岁以下的未成年人。如果我们发现在未获得监护人同意的情况下收集了未成年人信息，将尽快删除相关数据。

八、政策更新

我们可能会根据业务发展或法律法规变化更新本隐私政策。更新后的政策将在本页面发布，我们也会通过应用内通知提醒您关注变化。继续使用本应用即视为同意更新后的政策。
