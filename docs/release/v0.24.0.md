# 闪讯 v0.24.0 Release

发布日期：2026-05-24

---

## 应用简介

闪讯是一款全栈即时通讯应用，后端 Rust + PostgreSQL + WebSocket，前端 Flutter 多平台。支持文字/语音消息、好友管理、群聊、全局搜索等核心 IM 功能。

---

## 当前版本功能全览

### 认证与账号
- 短信验证码登录
- 密码登录
- GitHub OAuth 第三方登录
- 首次登录自动注册
- 登录日志记录（设备信息、IP、时间）
- 首次登录收到"闪讯团队"欢迎消息
- 修改密码 / 设置密码
- 个人资料编辑（昵称、签名、头像）
- 注销账号（邮件申请流程）

### 即时通讯
- 实时消息收发（WebSocket + Protobuf）
- 文字消息、表情消息、语音消息
- 微信风格聊天输入栏（表情面板 + 语音录制 + 加号菜单）
- 语音消息录制与气泡播放
- 会话列表（最近消息、未读数、时间戳）
- 消息本地缓存（Drift SQLite）
- 离线消息同步

### 好友与社交
- 通讯录（字母索引 + 拼音排序）
- 搜索添加好友（防抖 + 全屏 loading）
- 扫码添加好友（mobile_scanner）
- 好友申请 / 同意 / 拒绝
- 好友详情页（发消息、删除好友）
- 我的名片（二维码 + logo + 签名）

### 群聊
- 创建群聊
- 群成员管理
- 群消息收发

### 搜索
- 全局搜索（用户 / 消息 / 会话）

### 设置与隐私
- 设置页（微信风格分组列表）
- 关于闪讯（logo + 版本 + 简介）
- 用户协议 / 隐私政策（WebView 查看）
- 首次启动隐私协议弹窗（必须同意才能使用）
- 退出登录

### 系统特性
- 系统通知（id=0，蓝色铃铛图标）
- 闪讯团队消息（id=100000000，蓝色闪电图标）
- identicon 头像生成
- 多环境配置（dev / production）

## 体积优化措施

| 措施 | 效果 |
|------|------|
| 架构拆分（只打 arm64） | fat 包减半 |
| packaging 压缩（useLegacyPackaging） | 28 MB → 14 MB |
| R8 代码压缩 + 资源压缩 | ~10-15% |
| 代码混淆（--obfuscate） | ~5-10% |

---

## 已知限制

- AAB 构建在 Flutter 3.32.x 上可能报 strip debug symbols 错误，需安装 Android SDK Command-line Tools
- iOS 未经完整测试
- 语音消息依赖麦克风权限，首次使用时系统弹窗授权
