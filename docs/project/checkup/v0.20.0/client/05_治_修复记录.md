## fx_logger 包

本次新建了通用日志包 `client/packages/fx_logger/`，解决 print 残留问题的同时建立了长期的日志基础设施。

**设计要点**：
- 工厂缓存模式：`FxLog('tag')` 同名返回同一实例，随用随取
- 可插拔代理：`LogDelegate` 抽象接口，默认实现 `DebugLogDelegate`
- release 零开销：整个输出逻辑包裹在 `assert()` 中，release 模式编译器直接移除
- debugPrint 节流：不会像 print 那样在大量日志时丢帧
- ANSI 彩色输出：debug 默认色、info 蓝色、warning 橙色、error 红色

**使用方式**：
```dart
final _log = FxLog('Sync');
_log.d('开始同步...');
_log.w('重试中', error: e);
_log.e('连接失败', error: e, stackTrace: st);
```

**替换为自定义实现**：
```dart
FxLog.delegate = SentryLogDelegate();  // 对接 Sentry
FxLog.delegate = FileLogDelegate();    // 写入文件
```

**模块 tag 分配**：

|------|-----|------|
| flash_im_cache | `Sync` | sync_engine.dart |
| flash_im_chat | `Chat` | chat_cubit.dart |

| flash_im_chat | `ChatPage` | chat_page.dart |

## 收获与沉淀

### 1. 日志规范确立

从此项目有了统一的日志方案。新代码不再允许使用 `print`，`avoid_print` lint 规则会自动拦截。所有日志通过 `FxLog` 输出，带 tag、带级别、release 自动静默。

### 2. packages 目录建立

`client/packages/` 作为通用基础包的存放位置正式启用。与 `client/modules/`（业务模块）形成分层：
- `packages/`：不依赖项目业务的通用组件（fx_logger 等）
- `modules/`：项目业务模块（flash_im_* 系列）

### 3. 体检流程验证

本次是项目首次完整走完"望闻问切 + 治"的全流程。从发现 107 个问题到清零，验证了流程的可行性。后续每个版本做一次体检，跟踪趋势。
