## 主工程（占比 6.6%）

### home_page.dart（822 行，5 个 use_build_context_synchronously）

**问题**：5 处异步操作后使用了 BuildContext。虽然代码里有 `mounted` 检查，但 lint 认为检查方式不够严谨（检查的 mounted 和使用的 context 可能不是同一个 Widget 的）。

**潜在风险**：如果用户在异步等待期间快速切换页面，可能触发 "setState() called after dispose()" 错误。目前没有复现过，但在网络慢的环境下有可能出现。

**严重程度**：🟡 一般。建议后续改为在 async 操作前缓存需要的值，或使用更严格的 mounted guard。
