# 存档快照：v0.23.0 — 认证增强

- 日期：2026-05-23
- 节点总数：130（新增 3）
- 功能版本：`docs/features/auth/v0.0.3/`

## 变更摘要

认证系统三项增强：GitHub OAuth 登录、登录日志记录、首次登录欢迎消息。

主要改动：
- 后端：新增 OAuthProvider trait + GitHubProvider 实现，支持未来扩展 Google/Apple 登录
- 后端：新建 login_logs 表，每次登录记录 IP、平台、设备名、设备 ID、版本号
- 后端：首次登录时自动创建与"闪讯团队"（id=100000000）的会话并发送欢迎消息
- 后端：新增系统用户 id=0（系统通知）和 id=100000000（闪讯团队）种子数据
- 前端：登录页新增 GitHub 登录按钮（WebView 内嵌授权页，移动端专属）
- 前端：登录请求携带 device_info（platform、device_name、device_id、app_version）
- 前端：AvatarWidget 支持特殊头像（identicon:system 蓝底铃铛、identicon:team 蓝底闪电）
- 前端：登录按钮 loading 改为三点跳动动画
- 前端：输入栏有文字时加号隐藏、发送按钮显示
- 前端：数据库生命周期修复（登出时 disposeCache）
- 依赖：后端新增 reqwest + async-trait，前端新增 webview_flutter + device_info_plus + package_info_plus + uuid

## 新增节点

| 编号 | 功能节点 | 模块 | 端 | 说明 |
|------|---------|------|-----|------|
| I-15 | GitHub OAuth 登录 | flash-auth (oauth/github) | 后端 | OAuthProvider trait + GitHubProvider，code→token→user_info→登录/注册 |
| I-16 | 登录日志记录 | flash-auth (login_log) | 后端 | 每次登录写入 login_logs 表（IP、平台、设备） |
| D-42 | 欢迎消息 | flash-auth (welcome) | 后端 | 首次登录时创建与闪讯团队的会话并发送消息 |

## 依赖关系

- I-15 → I-02（复用 find_or_create 模式）
- I-16 → I-01（依赖 accounts 表）
- D-42 → I-16（通过 is_first_login 判断）

## 技术要点

- OAuthProvider trait 设计：未来加 Google/Apple 只需实现 trait + 加一行路由
- 欢迎消息用直接 SQL（flash-auth 不能依赖 im-message 避免循环依赖）
- 系统用户 id=0 用于群聊系统消息，闪讯团队 id=100000000 用于欢迎消息
- 前端数据库生命周期：登出时通过 sessionCubit.stream 监听自动 disposeCache
