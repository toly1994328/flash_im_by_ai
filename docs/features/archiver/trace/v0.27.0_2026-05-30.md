## 本次变更的局域网络

### 变更：Auth 域

**后端：**
- 新增 `scan_sessions` 表（token/status/user_id/expires_at）
- 新增 4 个 HTTP 接口：scan/create、scan/status、scan/confirm、scan/cancel
- `login_with_password` 支持闪讯ID + 邮箱 + 手机号三种账号格式
- `login` handler 改用 AppError 返回有意义的错误信息

**前端：**
- 桌面端登录页改为左右分栏布局（DesktopLoginBody 独立文件）
- 新增 QrLoginForm 组件（二维码 + 轮询 + 状态切换）
- 新增 ScanConfirmPage（手机端确认页）
- ScanPage 从 flash_im_friend 迁移到 flash_shared（通用扫码组件）
- WindowsButtons 组件化到 flash_shared
- LoginSegmentTab 桌面端去掉扫码 Tab，改为折角切换
- 窗口尺寸跟随登录状态变化（未登录 860x560，已登录 1200x800）
- Windows 平台使用黑体字体

## 运维流程（不分配编号）

- Windows 构建脚本 `scripts/build_center/windows/build.py`：flutter build + Inno Setup 打包 + MSIX 打包
- 图标生成脚本 `scripts/build_center/windows/gen_ico.py`
- 证书生成脚本 `scripts/build_center/windows/gen_cert.py`

- `seed.py` 兼容 Linux（curl 替代 curl.exe）+ 支持环境变量配置 BASE_URL
