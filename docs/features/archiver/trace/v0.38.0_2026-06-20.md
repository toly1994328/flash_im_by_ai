## 变更摘要

新建 fx_media 统一媒体管理包，将散落在 flash_im_chat / flash_cloud 的下载/缓存/播放/预览能力收敛为项目无关的通用包。同时修复 Android 后台 WS 断连和上传 broken pipe 问题。

核心能力：
- fx_media 包：统一下载管理（队列 + 并发控制 + id 去重 + 磁盘恢复）
- 全局音频播放器：播新停旧单例 + snapshotStream 状态流
- 图片缓存 Widget：CachedNetworkImage + onCached 路径回调 + 全屏预览入口
- 视频播放页：支持网络 URL + 本地文件双模式
- 文件操作工具：系统打开 / 另存为 / 打开文件夹（跨平台）
- 云空间媒体预览：视频点击播放、图片点击全屏、音频点击播放/暂停
- 缓存统一：聊天和云空间通过 fxMediaIdFromUrl 共享缓存，下载一次两端可见
- 迁移完成：ChatMediaHandler / AudioBubble / ChatCubit / FileDetailCubit 全部改用 FxMedia
- 删除 CloudDownloadManager、旧 VideoPlayerPage

额外修复：
- WS 断线帧缓存（pending queue）+ 前台恢复即时重连（WidgetsBindingObserver）
- 上传 broken pipe 自动重试（通过秒传 checkHash 恢复）
- 404 已删除资源友好提示
- 云空间配额变化自动刷新

## 关键架构改进

| 改进 | 之前 | 之后 |
|------|------|------|
| 下载管理 | 两套重复（FileCacheManagerImpl + CloudDownloadManager） | 一套 FxMedia.download |
| 音频播放 | 每个 AudioBubble 独立 AudioPlayer | 全局单例播新停旧 |
| 视频播放 | 只支持网络 URL | 网络 + 本地双支持 |
| 缓存共享 | 聊天/云空间各自独立 | 统一 id，一次下载两端可见 |
| WS 可靠性 | 断线时消息静默丢失 | pending queue + 自动重连补发 |
| 上传容错 | broken pipe 直接失败 | 秒传检查自动恢复 |
