# v0.42.0 存档快照 — 会话列表操作优化

> 日期: 2026-07-12 | 节点总数: 196 | 新增节点: 10

## 迭代位置

`docs/features/im/operation/v0.0.5/`

## 变更摘要

为 IM 会话列表补齐核心管理操作：置顶、免打扰、标记未读、删除、清空。
- 后端新增 3 个 toggle API + WS 推送扩展
- 前端补齐滑动/长按/右键交互层 + 置顶排序 + 清空聊天记录
- 清空会话采用本地时间戳过滤方案，遵循微信「各端独立」的用户心智
