## 变更摘要

云资源管理系统：自建 OSS 存储层重构 + 用户云空间配额管理。

核心能力：
- StorageBackend trait 抽象（LocalFs 实现，预留 S3）
- SHA-1 hash 文件去重 + 两步秒传（check → upload）
- 用户云配额（默认 100MB）+ 上传前配额预检
- file_objects 元数据表 + file_references 引用追踪
- WS STORAGE_QUOTA_UPDATE 帧实时推送配额变更
- "我的"页云空间卡片（蓝/黄/红/绿分色进度条）+ 详情页（圆环图）

## 数据库变更

新增 3 张表：
- `file_objects` — 文件元数据（hash 唯一索引、引用计数、上传者）
- `user_storage_quota` — 用户配额（默认 100MB）
- `file_references` — 文件引用关系（file_id ↔ message_id）

## 协议变更

- `ws.proto`: 新增 `STORAGE_QUOTA_UPDATE = 18`
- `message.proto`: 新增 `StorageQuotaNotification { used_bytes, quota_bytes }`
