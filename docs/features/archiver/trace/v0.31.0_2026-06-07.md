## 新增节点

| 编号 | 功能节点 | 层级 | 模块 | 简介 |
|------|---------|------|------|------|
| I-21 | 版本信息管理 | 基础设施层 | app-center | 后端 app_versions 表 + 版本查询/创建/发布接口 |
| P-73 | 版本检测与更新弹窗 | 前端业务层 | fx_updater + update_trigger | 启动后检测 + 弹窗 UI + 下载校验 + 平台策略分发 |

- I-21 依赖 I-01（共享 db pool）
- P-73 依赖 F-03（启动流程框架，检测时机）
- P-73 依赖 F-02（用户会话状态，获取版本号）
- P-73 -.-> I-21（HTTP 调用 GET /api/app/version）

## 新增/变更模块

| 模块 | 位置 | 说明 |
|------|------|------|
| app-center | server/modules/app-center/ | 新增后端模块：应用版本管理（CRUD + 发布控制） |
| fx_updater | client/packages/fx_updater/ | 新增通用包：版本检测 + 弹窗 + 策略接口 + 全局状态（已发 pub） |

- `build_android.py`：构建后自动 calculate meta
- `windows/build.py`：新增 `--port` 代理参数、`--pack-only` 仅打包、构建后 calculate meta
- `build_linux.sh`：构建后自动 calculate meta
- `upload/calculate.py`：安装包元信息计算工具
- `upload/update.py`：版本上传 + 创建记录工具
