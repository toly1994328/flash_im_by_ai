## 本次变更

本次为鸿蒙平台适配迭代，不涉及新的业务功能节点。

### 架构变更：数据层隔离

将 `flash_im_cache` 拆分为接口包 + 实现包，实现鸿蒙平台的编译兼容：

| 包 | 职责 | 依赖 |
|---|---|---|
| `flash_im_cache` | 纯接口（LocalStore + 模型 + SyncEngine + EmptyLocalStore） | 零原生依赖 |
| `flash_im_cache_drift` | drift 实现（DriftLocalStore + AppDatabase + DAO） | drift/sqlite3 |

上层业务模块（chat/conversation/friend）只依赖接口包，零改动。
