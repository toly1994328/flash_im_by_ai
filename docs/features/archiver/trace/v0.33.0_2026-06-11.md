## 技术决策记录

| 决策 | 方案 |
|------|------|
| 存储路径 | `{appSupportDir}/UserData/{userId}/{category}/{messageId}.{ext}`，用 `p.join` 确保平台分隔符 |
| localData JSON | `{path, thumbnail_path?, cached_at}` |
| 自动缓存范围 | 图片 + 音频 + 视频封面，文件/视频本体手动触发 |
| Windows 打开文件夹 | `Process.start('explorer.exe', ['/select,$path'])` |
| 发送限制 | FileSendLimits 可配置类，默认 50MB/2min |
