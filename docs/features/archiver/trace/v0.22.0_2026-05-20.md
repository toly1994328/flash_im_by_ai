# 存档快照：v0.22.0 — 聊天输入框优化

- 日期：2026-05-20
- 节点总数：127（新增 3）
- 功能版本：`docs/features/im/chat-input/v0.22.0/`

## 变更摘要

输入栏样式改为微信风格，新增 Emoji 表情面板和语音消息功能。

主要改动：
- 后端：proto 新增 AUDIO=4 枚举，generate_preview 新增 `[语音]`
- 前端：重写 chat_input.dart（微信风格 + TapRegion + 面板互斥切换）
- 前端：新增 emoji_panel.dart、voice_input/、audio_bubble.dart
- 前端：MessageType 重构为带 value 的增强枚举，收敛 int↔enum 转换
- 前端：ChatFileMixin 新增 sendAudioFromFile
- 依赖：新增 record、just_audio、permission_handler、flutter_svg

## 新增节点

| 编号 | 功能节点 | 模块 | 端 | 说明 |
|------|---------|------|-----|------|
| D-41 | 语音消息类型 | im-message (models) | 后端 | msg_type=4，proto AUDIO 枚举 |

| P-55 | 语音消息输入 | flash_im_chat (voice_input + audio_bubble) | 前端 | 按住录音、松手发送、上滑取消、语音气泡播放 |

## 依赖关系

- D-41 → D-06（消息存储）
- P-54 → P-11（功能面板）
- P-55 → P-11（功能面板）+ I-11（文件上传）+ D-41（语音消息类型）

## 技术要点

- `record_linux 0.7.x` 与 `record_platform_interface 1.5.0` 不兼容，通过主项目 `dependency_overrides` 升级到 `1.3.0` 解决
- `flutter_svg` 在多模块项目中子模块无法独立解析，通过主项目 `dependency_overrides` 解决
- 权限检测策略：按住说话时检测，无权限则请求后直接 return（不管授权结果），下次按住才录音
