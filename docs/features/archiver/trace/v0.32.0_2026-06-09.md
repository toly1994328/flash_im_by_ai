## 变更内容

本次为已有功能节点（P-11 功能面板、P-48 长按菜单、P-54 Emoji 面板）的桌面端交互适配，不引入新数据流或业务逻辑，不分配新编号。

### 改动项

| 改动 | 说明 |
|------|------|
| 表情面板浮层化 | 桌面端用 TolyPopover 从图标上方弹出，高度 360px，移动端不变 |
| 右键操作菜单 | 桌面端 onSecondaryTapUp 触发 TolyPopover 弹出竖向菜单，移动端保持长按 |
| @ 选择器弹窗化 | 桌面端用 adaptivePush 弹窄屏对话框，移动端保持全屏 push |
| 转发界面弹窗化 | 桌面端用 showDialog 包裹 ConversationPickerPage（不用 adaptivePush 避免独立 Navigator 问题） |
| Windows 窗口按钮贴顶 | Positioned(top:0, right:0) + kApp.isWindows 判断，仅 Windows 显示 |
| 群聊 @ 按钮 | 桌面端工具栏增加 @ 图标，点击插入 @ 字符触发选择器 |
| Emoji 扩充 | 从 48 个扩充到 88 个常用 emoji |

### 踩坑记录

| 问题 | 原因 | 解决 |
|------|------|------|
| 菜单有箭头 | DecorationConfig 的 isBubble 默认 true | 显式设 `isBubble: false` |
| 装饰加深 | DesktopContextMenu 自带边线阴影 + TolyPopover 默认装饰叠加 | 去掉组件自身装饰，由 Popover 统一管理 |
| 转发面板白屏 | adaptivePush 的独立 Navigator 导致 pop 结果丢失 | 转发场景直接用 showDialog |
| PopoverController 生命周期 | 在 StatelessWidget 的 build 中创建 | 不传 controller，用 builder 内 ctrl |
