## 变更摘要

云空间独立 Tab：从"我的"页面卡片升级为底部第 4 Tab，完整的文件浏览/详情/管理能力。

核心能力：
- 底部导航 4 Tab（消息/通讯录/云空间/我）
- 云空间 Tab：分色圆环配额概览（CustomPaint）+ 吸顶分类 Tab（SliverPersistentHeader）
- 文件列表：3 列网格（图片/视频）+ 列表（音频/文件），按日期分组，分页加载
- "全部"分类下网格左上角彩色类型标签，音频/文件显示图标占位 + 右下角大小
- 文件详情页：预览区 + 文件信息 + 本地缓存（背景进度下载 + 路径展示 + 复制/清除）+ 引用会话 + 删除
- 全局下载管理器（CloudDownloadManager 单例）：多文件并行下载，退出页面进度不丢失
- 确认弹框统一 showTolyPopPicker 底部弹出样式
- "我的"页面精简卡片：底部 3px 分色进度条，点击切换 Tab
- 后端：文件列表/详情/删除 3 个新接口 + original_name 字段 + /uploads 不压缩保留 Content-Length
