# 图片预览体验升级

版本：v0.0.5_media_preview　对应 tag：v0.35.0

## 背景

当前聊天中的图片展示存在体验问题：
- 气泡直接加载原图（大、慢）
- 预览页无 Hero 过渡动画，跳转生硬
- 不支持多图左右滑动
- 不支持下拉关闭手势
- 无图片缓存

后端已生成缩略图（`thumbnail_url`），但前端未使用。

## 目标

用 `tolyui_mediax` 库替换当前的图片气泡展示和预览实现，提升浏览体验：

1. 气泡显示缩略图，加载快
2. Hero 动画从气泡平滑过渡到全屏预览
3. 预览页支持多图左右滑动
4. 下拉手势关闭预览
5. CachedNetworkImage 缓存图片

## 不做

- 不改后端接口（thumbnail_url 已有）
- 不改消息数据结构（extra 字段不变）
- 不做视频预览改造（后续单独迭代）
- 不做图片编辑/涂鸦

## 影响范围

纯前端改动，限 `flash_im_chat` 模块 + App 层 Resolver 注入。
