# 云空间 Tab — 讨论记录

## 背景

[v0.0.6 云资源管理系统](../../im/core/v0.0.6_file_system/analysis.md) 实现了云资源管理的后端基础（StorageBackend、去重、配额、引用追踪）和"我的"页面的云空间卡片。本次迭代将云空间升级为底部独立 Tab，提供完整的文件浏览/详情/管理能力。

## 需求讨论

### 1. 云空间作为独立 Tab

用户希望云空间不再只是"我的"页面里的一个卡片，而是底部导航的一个独立 Tab。

当前底部 Tab 结构：消息 / 通讯录 / 我（3 个）

新结构：消息 / 通讯录 / **云空间** / 我（4 个）

### 2. 云空间 Tab 页面结构

- **顶部**：配额概览卡片（大号已用数字 + 分色进度条 + 图例）
- **中间**：分类 Tab（全部 / 图片 / 视频 / 音频 / 文件）
- **内容区**：
  - 图片/视频：3 列网格展示（缩略图），视频右下角显示时长
  - 音频/文件：列表展示（文件名 + 大小 + 时间）
  - 按月份分组（"2026年6月"分隔线）
- **交互**：点击进入文件详情页

### 3. 文件详情页

用户要求进入详情页，展示：

- **预览区**：图片大图 / 视频封面（可播放）
- **文件信息**：名称、大小、格式、上传时间
- **本地缓存状态**：
  - 是否已缓存（✅ / ❌）
  - 缓存大小
  - 可单独清除本地缓存（不影响云端）
- **引用会话列表**：该文件被哪些会话的消息引用，可点击跳转
- **删除操作**：删除云端文件释放空间

### 4. UI 风格

遵循闪讯现有风格：
- 灰色 AppBar（#EDEDED）用于 Tab 页
- 白色 AppBar 用于详情页
- 白色卡片分组，间隔 10px 灰色背景（#F5F5F5）
- 信息展示用标准 label-value 设置项样式
- 颜色：蓝图片、黄视频、红音频、绿文件

### 5. 后端需要新增的接口

- `GET /api/storage/files?category=image&page=1&limit=20` — 分页查询用户文件列表
- `GET /api/storage/files/{id}` — 文件详情（含引用会话列表）
- `DELETE /api/storage/files/{id}` — 删除文件（ref_count-1，归零时物理删除 + 回收配额）

## 待确认

- [x] "我的"页面的云空间卡片是否保留？→ **保留，但精简样式**（作为快捷入口）
- [x] 桌面端是否同步做？→ **先做移动端**，桌面端后续跟进
- [x] 文件列表的排序 → **按时间倒序**（最新的在前）
- [x] 删除文件时消息里怎么显示？→ **有本地缓存就展示本地；没有就显示"资源已删除"占位**
