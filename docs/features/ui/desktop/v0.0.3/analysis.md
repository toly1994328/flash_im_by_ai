# Web 加载优化 v0.0.3

## 功能概述

优化 Flutter Web 首次加载体验，解决白屏等待问题。本次改动属于基础设施优化，不涉及新业务功能。

## 问题背景

Flutter Web 产物体积大（~5MB 压缩后），首次加载白屏 3-6 秒。原因：
1. WASM 渲染引擎 + Dart 运行时 + 业务代码必须全部下载后才能渲染
2. 服务端未开启压缩，传输体积是原始大小
3. 无加载指示，用户只能盯着白屏

## 优化方案

| 方案 | 层级 | 效果 |
|------|------|------|
| Gzip/Brotli 压缩 | 后端 | 传输体积减少 ~70% |
| COOP/COEP 响应头 | 后端 | 启用 WASM 多线程渲染 |
| WASM 编译 | 构建 | 产物更紧凑 + 运行时更快 |
| Tree Shake Icons | 构建 | 字体文件减小 ~1MB |
| 科技感加载页 | 前端 | 消除白屏感知 |
| Web 端跳过隐私弹窗 | 前端 | 减少进入流程的阻断 |

## 不涉及

- 新增 API 接口
- 数据库变更
- 业务逻辑变更
- Deferred Loading（评估后暂缓，破坏性大收益小）
- Service Worker（浏览器 HTTP 缓存已满足二次秒开）
- CDN 加速（当前自托管已满足，未来有需要再上）
